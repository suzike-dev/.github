# suzike-dev · 组织简介

> 面向 MBSE / 智能体工程的工具链与实验场 —— 从 Simulink 模型到需求、从需求到 AI 代理。

## 🚀 我们在做什么

| 方向 | 代表项目 | 说明 |
|------|----------|------|
| 🌡️ 仿真工作台 | thermal-workbench | 热管理仿真：建模、工况编排、结果后处理 |
| 📋 需求工程 | model-code-to-srs · requirements-copilot | 模型自动生成 SRS，AI 辅助需求评审 |
| 🔌 工具集成 | polarion-mcp-server | 用 MCP 协议把 Polarion ALM 接入 AI 代理 |
| 🤖 智能体 | agentic-workbench · Matlab-Simulink-SuperAgent | 编排、评估、可观测性与建模自动化 |
| 🛠️ 嵌入式 | hw-led-blink · esp32-sensor-hub | 嵌入式 Rust 与传感器固件 |

## 🧭 如何参与

1. **提问 / 讨论** → 使用组织 Discussions，提问前请先搜索历史帖
2. **提 Issue** → 选对仓库，附上复现步骤与版本信息
3. **提交 PR** → 遵循各仓库的贡献指南，CI 全绿后再请求评审
